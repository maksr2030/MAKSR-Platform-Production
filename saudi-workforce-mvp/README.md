# Saudi Sovereign Workforce Operational MVP

نموذج تشغيلي أولي لمنصة القوى العاملة السعودية السيادية.

يتضمن النموذج:
- غرفة قيادة إقليمية
- إدارة احتياج المنشآت
- الانتقال الوظيفي الموسمي
- التحقق والتصاريح
- حماية العامل
- الجاهزية والتقارير

النسخة الحالية نموذج عرض وتشغيل تجريبي ببيانات افتراضية، ولا تصدر تصاريح حكومية فعلية.
